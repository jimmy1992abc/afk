# 1.3.0 release notes

## Changes

- Add `afk-gemini-review`, an optional external review role that runs Gemini 4
  Argon (`gemini-4-argon-high`) through the operator's signed-in Antigravity
  CLI (`agy`). No API key is used.
- Accept `gemini` as an explicit `gates:` / `priority:` family, a handoff role
  flag (`-gemini`) and a review receipt family.
- Accept a Gemini verdict only from a complete stream-json turn whose `init`
  event names the requested model and which shows no delegation to subagents.
- Share the working-tree drift caution and untracked-file notice between the
  Claude and Gemini gates. The Claude prompt is unchanged.

## Compatibility and upgrade

Built-in defaults and the fallback pool are unchanged: Gemini runs only when an
explicit profile or role flag selects it, or when the skill is invoked
directly. No configuration migration is required.

To use the gate, install the Antigravity CLI, sign in once by running `agy`,
and put it on `PATH` (`~/.gemini/bin/agy install`) or set `GEMINI_GATE_BIN`.
`GEMINI_REVIEW_MODEL` accepts only a versioned `gemini-*` ID; run `agy models`
to list the IDs the account offers. A missing CLI, signed-out account,
unavailable model or rate limit skips the role.

The Gemini gate is not read-only by construction: plan mode and the CLI sandbox
restrict the agent. It receives the raw diff, and `agy` keeps the conversation
under `~/.gemini/antigravity-cli/`. Prefer Claude or Codex where both qualify.

Reinstall or update the plugin to load the new cache version.
