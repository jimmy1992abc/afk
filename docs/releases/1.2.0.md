# 1.2.0 release notes

## Changes

- Default Codex review to Sol 6.1 and Claude review to Opus 5.5, both at high
  effort. Default DeepSeek review and relay to DeepSeek Flash.
- Improve quoted credential redaction, refuse provider redirects and resolve
  Windows reviewers without implicit checkout executable search.
- Include repository-wide untracked files in uncommitted reviews, retain caller
  executable selection and surface inventory or forge-configuration failures.
- Keep direction result limits consistent and preserve observed dispatch when
  finalizing retained audits after a runtime upgrade.
- Support deliberate session handoffs and clarify standalone review routing.
- Validate tracked Markdown and use each reviewer's latest decisive approval.

## Compatibility and upgrade

No new configuration keys or state migration are required. Existing model and
effort overrides take precedence, and Luna/Fable shortcuts remain compatible.
Repair cycles stay uncapped by default, structural P2 repairs remain supported,
absent CI policy remains expected, and owner review still controls merge.

Direction auditing stays off with pending qualification. Qualify the actual
current runtime before enabling dispatch; finalizing retained audits does not
renew qualification. Reinstall or update the plugin to load the new cache version.
