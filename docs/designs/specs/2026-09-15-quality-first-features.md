# Quality-first workflow features

## Accepted scope

Stage references reduce repeated instructions while preserving standalone skill
entry points. Handoffs retain source authority, findings, evidence and consumed
allowances. Local completion supports work without automatic publication.
Optional direction audits compare retained intent with a specific candidate;
observed-host evaluations retain evidence for manual behavior assessment.

Existing policy remains: structural P2 findings are repairable, repair cycles
have no numeric default cap, absent CI policy means `expected`, and owner review
controls merge. Explicit resource budgets remain binding and proportionally
increase only with sourced operator authorization. Model aliases, repository
identity, release duties and automatic resume behavior remain unchanged.

## Boundaries

Direction mode defaults to `off`. The bundled runtime has a pending transport
qualification; live dispatch requires a reviewed qualification for its actual
fingerprint. Fixture success supplies no live-provider or agent-quality claim.
The observed native adapter accepts its explicitly supported macOS ARM64 CLI
build; unsupported hosts remain unavailable. Evaluation execution stays manual.

State and audit helpers constrain artifacts when invoked (level 2). Stage
routing, faithful handoffs, review depth and completion remain workflow doctrine
(level 3) or model judgment (level 1), with no orchestration runtime added.

## Timeline and dataset review

Baseline and policy precede audit preparation. Reservation precedes dispatch and
remains charged after interruption. Results retain original bindings; endpoint
checks reread current state and target. Configuration edits cannot amend retained
authority. Evaluation manifests bind immutable support and evaluator bytes;
resumes check those bytes before reusing evidence. Ready transitions precede
current-revision CI validation.

The deterministic suites cover all bundled scenarios and instruction routes,
including malformed and unavailable inputs. Real Git repositories and local HTTP
servers exercise external boundaries. Private provider traces are not present;
no live campaign or transport qualification is claimed by these checks.
